----------------------------------------------------------------
1) HABILITAR DEPURACION USB EN LA PDA (una sola vez)
----------------------------------------------------------------
- Ajustes -> Acerca de -> pulsar 7 veces "Numero de compilacion".
- Ajustes -> Opciones de desarrollador -> Depuracion USB -> Activar.
- Conecta la PDA a la PC por cable USB (que transmita datos).
- En la PDA toca PERMITIR en el aviso de depuracion.

----------------------------------------------------------------
2) VERIFICAR QUE LA PC VE LA PDA
----------------------------------------------------------------
adb devices
  Salida esperada:
    List of devices attached
    <serial>  device

- Si sale "unauthorized": toca PERMITIR en la PDA.
- Si sale "offline" o no aparece: cambia el cable USB.

----------------------------------------------------------------
2b) DESINSTALAR LA APP ANTERIOR (IMPORTANTE)
----------------------------------------------------------------
La app vieja "PDA Print Service" (paquete com.sactel.pdaprint)
usa el MISMO puerto WebSocket 8091. Si queda instalada, el servicio
de impresion del APK nuevo no podra abrir el puerto.

  adb uninstall com.sactel.pdaprint

Verificar que quede SOLO la nueva:
  adb shell pm list packages | grep sactel
  -> debe aparecer: com.sactel.tickets

----------------------------------------------------------------
3) INSTALAR EL APK NUEVO
----------------------------------------------------------------
adb install -r /var/www/sactel.lan/rutas/dist/SACTel_Tickets_v1.0.apk
  -r  = reinstala conservando datos.
  Salida esperada: Success

Si falla (INSTALL_FAILED_UPDATE_INCOMPATIBLE, firma distinta):
  adb uninstall com.sactel.tickets
  adb install /var/www/sactel.lan/rutas/dist/SACTel_Tickets_v1.0.apk

----------------------------------------------------------------
4) REVISAR LA INSTALACION
----------------------------------------------------------------
adb shell pm list packages | grep sactel.tickets
adb shell pm path com.sactel.tickets
adb shell dumpsys package com.sactel.tickets | grep versionName
adb shell am start -n com.sactel.tickets/.MainActivity

----------------------------------------------------------------
5) DESPUES DE INSTALAR (en la PDA)
----------------------------------------------------------------
- Abre la app: pide permisos BLUETOOTH_SCAN, BLUETOOTH_CONNECT
  y POST_NOTIFICATIONS -> CONCEDER TODOS.
- Enciende Bluetooth del sistema.
- La app carga la web de tickets y arranca el servicio de impresion.

----------------------------------------------------------------
6) LOGS / DIAGNOSTICO
----------------------------------------------------------------
adb logcat -s PdaPrint:P        # logs en vivo
adb logcat -d | grep -i pda      # despues de una impresion

----------------------------------------------------------------
7) DESINSTALAR (si hace falta)
----------------------------------------------------------------
adb uninstall com.sactel.tickets
  (Primero desmarcar como administrador de dispositivo si se activo)
